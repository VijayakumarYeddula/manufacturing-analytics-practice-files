# Manufacturing Analytics for Engineers: practice files

Free practice files for the video course **Manufacturing Analytics for Engineers (Power BI)** by Vijayakumar Reddy Yeddula, Mechanical Product Engineer.

Use them to follow the 9 course sections in free Power BI Desktop: from raw plant data to a finished dashboard.

> **Fictional data.** Engxtech Manufacturing is a fictional plant (12 machines on 3 lines, April–September 2026). Every number is synthetic. No real company data is included.

## What is inside

| Folder | Contents |
| --- | --- |
| `data/` | `Plant_Analytics_Training_Data.xlsx` (Machines, Parts, ProductionLog, MaintenanceLog, SensorReadings, QualityInspections + README sheet) and `Energy_Exports/` (one CSV per month; the "- Copy" file is a deliberate duplicate for the Section 4 exercise) |
| `templates/` | `Data_Dictionary_Template.xlsx`, `Engxtech_Theme.json` (course colours) |
| `powerbi/start/` | `Section01_Engxtech.pbix` … `Section09_Engxtech.pbix` (start file for each section) |
| `powerbi/finished/` | `Section01_Finished.pbix` … `Section09_Finished.pbix`, `Section02_Start.pbix` |
| `docs/` | `Formula_Cheat_Sheet.pdf`, `Section09_Capstone_Brief.pdf` |
| `Engxtech_Practice_Data.zip` | everything learners need in one download |

## How to start

1. Download `Engxtech_Practice_Data.zip` (or the whole repository) and unzip it, for example to `Documents\Engxtech`.
2. Install Power BI Desktop (free, Windows only). No account or paid licence is needed.
3. Open a `.pbix` file. If Refresh cannot find the data: **Home › Transform data › Data source settings › Change Source…** and point to `data/Plant_Analytics_Training_Data.xlsx` (and, from Section 4, the `data/Energy_Exports` folder). Then **Close › Apply changes**.
